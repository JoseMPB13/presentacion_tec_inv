## 📱 Modo Control Remoto Móvil con Glosario y Notas Privadas
La aplicación incluye un sistema de doble vista diseñado para la defensa formal con proyector:
1. **En la Pantalla / Proyector (Laptop):**  
   Muestra únicamente las diapositivas limpias en alta resolución, sin notas, sin temporizador y sin elementos distractores para el docente evaluador.
2. **En el Celular del Expositor:**  
   Al escanear el código QR proyectado en la laptop (o acceder con `?remote=1`):
   - **Botones táctiles grandes:** `[◀ ANTERIOR]` y `[SIGUIENTE ▶]` para cambiar diapositivas cómodamente mientras camina por el aula.
   - **Glosario Dinámico ("en cristiano"):** Tarjeta con las palabras difíciles de la diapositiva actual explicadas en lenguaje simple.
   - **Guion Verbal Paso a Paso:** El texto exacto y natural para decir en voz alta sin trabarse.
   - **Metáfora Cotidiana:** Analogía para romper el hielo o aterrizar la teoría.
   - **Pregunta del Jurado y Respuesta Modelo:** La consulta típica del docente y cómo responderla con seguridad técnica.
   - **Frase de Pase Formal:** La transición protocolar para ceder el turno al siguiente compañero.
   - **Sincronización en tiempo real:** Mediante WebSockets seguros (MQTT Relay) y canales locales.

- **`F11`:** Pantalla completa del navegador.
- **`Esc`:** Cerrar cualquier ventana emergente o modal.
